Yardım linkini aç

Dinleyen keşif listesindeki spark / swift / warm / easy rozetleri, son mesajlara göre hesaplanan medyan yanıt gecikmesi ile karşılaştırılır. Burada üst sınırları saniye olarak girersin; medyan ≤ spark → spark, ≤ swift → swift, ≤ warm → warm, üzeri → easy.

Yanıt hızı eşikleri (saniye)

Varsayılan fabrika değerleri: spark ≤ 300s (5 dk), swift ≤ 1800s (30 dk), warm ≤ 21600s (6 saat). Kayıt yoksa API bu sabitleri kullanır. Kayıt sonrası spark < swift < warm zorunlu.
